## 网站部署的钱花在哪四项

四项里，域名和服务器是看得见的固定支出，带宽和备案是容易被低估的部分。域名按年租，服务器按配置包月或按量付费，带宽可以买固定值也可以按流量结算，备案本身不收费，但要花时间。

| 成本项 | 计费方式 | 参考数据 | 注意点 |
| --- | --- | --- | --- |
| 域名 | 按年租用 | 各后缀和注册商价格不同，Cloudflare Registrar 按成本价注册 | 价格随后缀、注册商变化 |
| 服务器 | 按 CPU、内存、系统盘配置计费 | 案例规格：1 vCPU 1 GiB | 配置可升降，低流量不必买高配 |
| 带宽/流量 | 固定带宽包月，或按实际流量计费 | 2022 年阿里云案例：4M 固定带宽 155.60 元/月；按流量 0.8 元/GB | 流量波动大选按流量，并设上限 |
| 备案 | 免费 | 国内主机需备案，约 10~20 个工作日 | 海外主机免备案 |

备案这一项本身不花钱，但当时（2019 年前后）阿里云要求服务器购买时长在 3 个月以上才具备申请资格，按月买的试用机备不了案。具体门槛以云厂商当前要求为准。

## 带宽和流量：账单里最容易超支的一项

固定带宽买的是速度上限，按流量买的是实际搬运的数据量。小流量网站选错计费方式，费用能差出十几倍。

先把单位换算记住：1M 带宽 = 128KB/s。带宽用 bit 计，下载速度用 Byte 计，差 8 倍。2M 对应 256KB/s，4M 对应 512KB/s。

看一个具体例子。一个页面压缩后实际传输 443KB，每天 1000 个访问：

- 每天流量：1000 × 443KB ≈ 0.42GB
- 按 0.8 元/GB 算：约 0.34 元/天，一个月 9 元左右
- 同样的量如果买 4M 固定带宽：155.60 元/月

反过来，如果 4M 带宽真的被跑满，每天能传出约 42GB，按流量计费一天就是 33 元、一个月近千元。所以“固定带宽和按流量哪个便宜”没有统一答案，看你的站有没有持续吃满带宽。

实操建议：

- 日访问几百到几千、以文字和图片为主：按流量计费，同时把最大带宽限制在 25M 这类可控值，防止被刷流量时账单失控。
- 访问量稳定、几乎全天都有人来：固定带宽更省心，费用不随访问量浮动。
- 图片、视频多的站：先压缩资源，否则流量费超出预期。对象存储选不收出口费的服务（比如 Cloudflare R2）能再省一笔。

## 国内服务器和海外服务器，差的是一道备案

国内主机必须完成 ICP 备案，域名才能正常访问；海外主机不需要备案，买了就能用。备案免费，成本是时间：一般 10~20 个工作日。

备案期间可以先把域名解析到服务器，等备案通过再正式对外开放。如果站点面向国内用户、打算长期做，这道流程值得走；如果只是临时展示、测试，或者面向海外用户，选海外主机或静态托管能省掉这段等待。

有个细节常被搞混：备案的对象是域名，不是服务器。一个网站要不要备案，取决于它用的主机在国内还是国外。

## 把成本压到接近零的几条路

纯静态网站可以做到几乎没有服务器成本。静态站由简单 HTML 页面组成，加载快，部署只要几秒到几分钟，动态功能可以通过 API 或无服务器函数后期加上。

具体有几条路：

1. **静态托管平台**。Cloudflare Workers 可以直接部署静态站点和全栈应用，兼容 Next.js、React、Vue、Svelte、Astro 等框架，从命令行或 Git 集成都能发布。Firebase Hosting 则是一条命令把静态内容推到全球 CDN，自定义域名自带端到端 HTTPS。
2. **免费额度和赠金**。Google Cloud 新用户有 300 美元赠金，另有 20 多种提供“始终免费”用量的产品，静态站点和轻量后端都能覆盖一部分。
3. **无服务器后端**。Cloudflare Workers 这类平台按实际运行的计算付费，不用先买带宽；Google Cloud 的 Cloud Run 适合跑容器化的动态站点。
4. **对象存储**。图片和静态资源放对象存储，Cloudflare R2 不收数据出口费，比传统对象存储少一项按流量计的费用。

这些方案的边界也说清楚：静态站要加登录、评论、支付，得接 API 或函数；面向国内用户的站点，海外平台的访问速度和备案合规仍要单独考虑。

## 常见问题

**部署一个网站最低要多少钱？**

静态站点用免费托管额度，固定支出只剩域名年费；动态站点最低从低配云服务器起步。2022 年阿里云案例中，每天 1000 访问的流量费约 9 元/月，服务器本身的费用另算。

**1M 带宽够用吗？**

1M 带宽的下载峰值是 128KB/s。443KB 的页面，一个用户完整加载约 3.5 秒，同时来几个人就得排队。个人低流量站勉强够用，访问量稍大建议 2M 以上，或者直接按流量计费。

**备案要花钱吗？**

备案本身免费。成本是时间，通常 10~20 个工作日，期间服务器要保持购买状态，且购买时长要满足云厂商的要求。

**静态网站还需要买服务器吗？**

不需要。静态站可以直接托管在 Cloudflare Workers、Firebase Hosting 这类平台上，分发和 HTTPS 由平台负责。

**按流量计费会不会突然很贵？**

有被刷流量的风险。开通时设置最大带宽上限，把最坏情况下的费用控制住，再根据实际用量调整。
